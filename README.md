# Hangman Game



##  Description

This project is my first one as a young developer learning python.
Its only goals were to help me learn how to use python language and to test 
my skills in that language.


The concept of the game is really simple, and you might know it.

You have to find the different letters of a word with a maximal number of 14 mistakes
(the time that the man be hanged). I had a mode that let you choose the number of letter in the word.
All the rules of the game were explained in the program.
